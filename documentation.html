What the archive forgot

01 — Overview

This document describes a prototype AI tool built to detect, demonstrate, and visualise misattribution in digital archive systems. The tool operates across two registers simultaneously: as a misattribution detection engine that queries multiple large language models (LLMs) and compares their responses against a researcher-built Record of Truth; and as an exhibition system designed for deployment across 12 LED screens in a museum space.

The core argument the tool demonstrates is structural: misattribution is not simply a cataloguing error made by individual institutions. It is a condition that propagates. An absence of a nationality qualifier in a Library of Congress authority record flows downstream into WorldCat, into national library aggregators such as Trove, into museum catalogues, and finally into the training data of LLMs — where it is replicated as if it were fact. Correcting the record upstream does not automatically correct what has been absorbed downstream.

The exhibition makes this process visible — without text, through distortion and clarity alone.

Dataset 1 — Parajanov Bibliographic Dataset

305 bibliographic records drawn from Trove (NLA), WorldCat/OCLC, ACMI, NGV Library, QAGOMA Cinémathèque, and State Library Victoria. Each record documents how Sergei Parajanov is identified in terms of nationality, name form, and subject headings.

Archive System type Misattribution found
Trove (NLA) National aggregator Labelled "Soviet" — Armenian identity erased
WorldCat / OCLC Global bibliographic Multiple transliteration variants; "Soviet" throughout

The Record of Truth establishes the correct form for all 305 records: Parajanov, Sarkis Hovsepi [Sergeĭ Iosifovich Paradzhanov, 1924–1990], with nationality Soviet-Armenian (Georgian-born Armenian).

Dataset 2 — Malevich / Exter / Pagava / Kakabadze Artwork Dataset

354 artwork catalogue records drawn from MoMA (New York), NGA (Canberra), NGV (Melbourne), Centre Pompidou (Paris), Yale University Art Gallery, Stedelijk Museum (Amsterdam), and others.

Kazimir Malevich — 272 records

Correct: Ukrainian-born (Kyiv); Polish ethnic heritage; b. 1879

Alexandra Exter — 44 records
Labelled: Russian
Correct: Ukrainian-born (Kyiv); trained Kyiv School of Art; émigré to Paris 1924
MoMA frames her work within "A Revolutionary Impulse: The Rise of the Russian Avant-Garde" — misattribution embedded in the exhibition title itself, not just the catalogue field.
Vera Pagava — 19 records
Labelled: Empire Russe
Correct: Georgian-born (Tbilisi); émigré to Paris via Germany 1923; never naturalised French
All 19 Centre Pompidou records use "Empire Russe" — technically a birthplace fact but functioning as imperial erasure of Georgian national identity. Pagava's family fled precisely to preserve Georgian identity before Soviet annexation (1921).
David Kakabadze — 19 records
Labelled: Absorbed into Société Anonyme "Russian avant-garde" canon
Correct: Georgian-born (Kutaisi/Tbilisi); studied Paris 1919–1927; returned Soviet Georgia 1927
Yale field records correctly note "Georgian" — but structural misattribution via the 1984 Herbert Catalogue Raisonné, which frames the entire Société Anonyme collection within a Russian/Soviet avant-garde narrative. Misattribution invisible at field level.

Propagation chain

Both datasets reveal the same downstream structure. An authority record at the Library of Congress that lacks a nationality qualifier does not simply remain neutral — the absence propagates as if it were a positive assertion. The chain moves from authority record to aggregator (WorldCat) to national catalogue (Trove) to institutional catalogue (museum) to LLM training data to public-facing AI systems. At each stage the error becomes more entrenched and harder to correct upstream.

03 — The Misattribution Detection Tool

The tool has two components that operate in parallel: a backend detection engine and a frontend exhibition system. Both are built to work offline or with live cloud LLMs depending on the exhibition context.

Multi-LLM misattribution detection

Following the principle that misattribution is "baked into" AI systems through their training data, the tool queries three LLM systems with an identical prompt about each artist and compares the responses against the researcher-built Record of Truth.

System Type Finding
Claude (Anthropic) Cloud LLM Describes Malevich as "Russian avant-garde artist"; Parajanov as "Soviet film director"
GPT-4o (OpenAI) Cloud LLM Same misattribution — "Russian avant-garde", "Soviet filmmaker"
LLAMA 3 (Ollama) Local / offline LLM Same misattribution — confirms that the error is model-independent

All three systems — cloud and local, from different organisations — produce the same misattribution independently. This demonstrates that the error is not the failure of a single system but a structural condition of the training data. The tool displays these three responses alongside the Record of Truth, making the gap visible to visitors in real time.

Visitor kiosk — what the visitor sees

A touch screen at the entrance to the exhibition allows visitors to select an artist and tap "Ask the archive". The screen splits into four columns: one for each of the three LLM systems, and a fourth column showing the researcher's Record of Truth. Each LLM response appears character by character. A bar at the bottom fills to show what proportion of AI systems produced the misattribution. No prior knowledge of the artists is required.

API endpoints

Endpoint Function
/api/compare?artist=X Returns all three LLM responses + Record of Truth for artist X
/api/query?artist=X Single LLM query (Claude) with misattribution assessment
/api/detect?url=IMG&artist=X Vision query — sends artwork image to LLM, returns assessment
/api/images?artist=X Returns image manifest showing which artworks are ready for vision queries
/api/stats Dataset summary statistics

04 — Exhibition Design: 12-Screen LED Installation

The exhibition display runs as a continuous loop across 12 LED screens assembled together. Each screen runs a fullscreen browser window showing its assigned section of the shared canvas. Together they compose one large image. The default grid is 4 columns × 3 rows; this can be reconfigured to 3×4, 6×2, or a linear 12×1 arrangement from the curator control panel.

Visual language

The exhibition uses no text and no colour coding tied to national identity. The only visual language is distortion (misattribution) and clarity (truth). The palette is neutral throughout — black, white, and grey. Fragmentation, pixelation, glitch, and noise show the corrupted state. A whole, sharp, luminous image shows the corrected state.

Eight phases — continuous loop

01
Pristine
The artwork appears clean and whole — a quiet white glow, the image as it was made, before the archive touched it.
02
Label Applied
A dark rectangular mark descends onto the image — no text, no colour, just weight and opacity. The wrong classification settles.
03
Corruption
The image fractures. Pixels break into blocks, glitch bars tear across, shards drift away. The image as the archive made it.
04
Propagation
Distorted copies of the image appear at the edges of the 12 screens. Archive nodes activate — library, museum, AI — the error flows downstream.
05
Machine Gaze
Three scan bars of different intensity sweep across the corrupted image — cloud LLM, local LLM, library system. All confirm the wrong answer.
06
Intervention
A single white vertical beam cuts through. The distortion dissolves around it. The researcher's correction enters.
07
Truth
The image returns — whole, sharp, luminous. Smaller correct copies orbit the centre, connected by fine lines. The work restored.
08
Fade
The screens go dark. The cycle resets with the next artist. The loop continues — as the error does, until corrected.

Screen synchronisation

When all 12 screens run from a single exhibition computer, phase timing is shared via the browser's localStorage — screen 1 writes the clock, screens 2–12 read it. All 12 advance through the phases in lockstep. For multi-machine deployments, a server sync endpoint provides the shared clock across a local network.

Artwork images

The visualization displays actual artwork images when available — loaded from an image directory mapped to dataset record IDs (MAL-001, EXT-001, KAK-001, PAG-001, etc.). 78 records in the dataset have direct image URLs; 16 of 19 Kakabadze records at Yale are fully open-access and ready for LLM vision queries without additional licensing. When images are provided via Google Drive, the image pipeline downloads and maps them automatically. When no image is available, the system uses a geometric glyph unique to each artist.

06 — Conceptual Framework

The tool is designed to test how provenance can work as infrastructure within a museum exhibition context. It demonstrates three interlinked conditions identified through the dataset research:

1. Metadata errors are replicated and entrenched. When the Library of Congress creates or maintains an authority record without a nationality qualifier, that absence propagates through every system that inherits from it. WorldCat, Trove, institutional catalogues — all downstream systems receive and replicate the gap as if it were a positive fact.

2. These entrenchments are replicated in LLMs. Large language models trained on web-scale data absorb the cataloguing errors of the institutions that produced that data. The tool demonstrates this empirically: Claude, GPT-4o, and LLAMA all independently describe Malevich as a "Russian avant-garde artist" and Parajanov as a "Soviet film director" — because those are the labels that dominate the digital record.

3. Correction is not obvious, and the ground truth struggles to go back upstream. The researcher has built a parallel Record of Truth — three additional columns for each of the 659 records showing what the nationality label, name form, and subject headings should have been. The exhibition makes visible both the error and the correction, and the difficulty of the distance between them.

The exhibition is therefore not only an artwork. It is a demonstration of infrastructure — of how digital systems shape what can be discovered, legitimised, and remembered within cultural memory.
